# 机票价格监控（桌面悬浮窗）

监控 **北京 → 悉尼 / 堪培拉** 往返机票价格，出现「监控期新低」或「明显低于近月趋势」时，
通过桌面常驻悬浮窗 + Windows 弹窗 + 提示音提醒你果断下单。

- 数据源：Google Flights 实时价（`fast-flights`）+ Travelpayouts 近月趋势兜底（可选）
- 默认窗口：去程锚点 `2026-09-26`、返程锚点 `2026-10-05`，各 ±2 天灵活找最低
- 省钱优先：可接受较多中转 / 较长等待，自行中转 / 长中转 / 红眼等风险会标注出来

## 运行

```powershell
# 可选：复制示例配置后按需修改日期、航线和最晚落地日
Copy-Item config.example.json config.json

# 首次：安装依赖（已在 .venv 中装好，可跳过）
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 启动（无控制台窗口）
.\.venv\Scripts\pythonw.exe run_flight_monitor.pyw

# 调试（带控制台，能看到报错）
.\.venv\Scripts\python.exe run_console.py
```

悬浮窗：显示**往返总价**，并分「**去程 / 返程**」两栏展示日期、时刻、机场中文名、中转城市/时长、全程耗时、风险标注、趋势 sparkline。
- **价格为 1 人经济舱含税往返总价**；去程为最优往返的实际去程，返程为该返程日「中转少/耗时短」的代表行程（价格以往返总价为准，鼠标悬停返程栏有说明）。
- **鼠标滚轮**：在窗口上滚动即可放大 / 缩小（0.7–2.2×，自动记忆）
- **窗口置于桌面最底层**，不遮挡其它应用；可按住拖动到任意位置
- **刷新**：立即查询一次
- **订票**：在浏览器打开对应的 Google Flights 预订页
- **⚙**：设置（日期窗口 / 缓冲天数 / 舱位 / 中转与全程上限 / 提醒阈值 / 刷新间隔 / token / 提示音 / 开机自启）
- **✕**：隐藏到系统托盘（托盘图标右键可再次显示 / 刷新 / 设置 / 退出；双击托盘图标显隐）

## 提醒逻辑（不设死价）

- **新低**：低于监控期内历史最低价
- **低于趋势**：低于趋势基准约 ≥10%（阈值可调）
  - 趋势基准默认由**插件自建历史价**自动计算（最近 N 天价格中位数，零 token）；样本不足时显示「积累中」，多刷新几次即可
  - 若在设置里填了 Travelpayouts token，则改用其更广口径的近月基准
- **去抖**：默认 12 小时内不重复提醒同等或更高价

## Travelpayouts token（完全可选）

**不填也有趋势基准**——默认用插件自己积累的历史价计算。只有想要更广的市场口径时才需要，注册流程较繁琐（需提供可访问网站）：
<https://www.travelpayouts.com/>

## 配置文件

`config.json`（首次保存设置后生成，也可从 `config.example.json` 复制）。可手动编辑 `routes` 增删监控航线，或通过 `arrive_home_by` 限制返程最晚落地日期。该文件可能包含 token，因此不会提交到 Git。
数据库 `prices.db` 存价格历史（用于新低判定与趋势图）。

## 备注

- `fast-flights` 是非官方接口，偶发限流 / 返回空 → 已做结果校验 + Travelpayouts 兜底。
- 北京→堪培拉无直飞；直达堪培拉的联程票时有时无（Google 数据稀疏），主力监控为北京→悉尼。
